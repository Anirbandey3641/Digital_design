# 16-bit Arithmetic Logic Unit (ALU) — Verilog RTL

## Overview

This project implements a **16-bit Arithmetic Logic Unit (ALU)** using Verilog HDL.

The ALU performs arithmetic, logical, shift, and comparison operations based on a **4-bit operation-select input**. The design also generates four status flags: **Carry, Zero, Sign, and Parity**.

The ALU was designed using combinational Verilog logic and functionally verified using a **self-checking Verilog testbench** in **Xilinx Vivado**.

## ALU Operations

The ALU uses a 4-bit `ALU_Sel` input to select one of nine supported operations.

|   `ALU_Sel`   | Operation   | Description                   |
| :-----------: | :---------- | :---------------------------- |
|     `0000`    | ADD         | `A + B`                       |
|     `0001`    | SUB         | `A - B`                       |
|     `0010`    | AND         | `A & B`                       |
|     `0011`    | OR          | `A \| B`                      |
|     `0100`    | XOR         | `A ^ B`                       |
|     `0101`    | NOT         | `~A`                          |
|     `0110`    | LEFT SHIFT  | `A << 1`                      |
|     `0111`    | RIGHT SHIFT | `A >> 1`                      |
|     `1000`    | COMPARE     | `1` if `A < B`, otherwise `0` |
| `1001`–`1111` | RESERVED    | Output set to `0`             |

### Comparison Operation

For `ALU_Sel = 1000`:

```text
A < B  → ALU_Out = 16'h0001
A >= B → ALU_Out = 16'h0000
```

## Status Flags

The ALU generates four status flags:

|   Flag   | Description                                                                                                    |
| :------: | :------------------------------------------------------------------------------------------------------------- |
|  `Carry` | Indicates carry-out during addition, borrow during subtraction, or the bit shifted out during shift operations |
|  `Zero`  | Becomes `1` when `ALU_Out` is zero                                                                             |
|  `Sign`  | Represents the most significant bit of the result, `ALU_Out[15]`                                               |
| `Parity` | Indicates even parity of the 16-bit output                                                                     |

### Carry Flag

For addition:

```text
A + B
```

the carry flag represents the 17th bit generated by the addition.

For subtraction, the implementation uses:

```verilog
Carry = (A < B);
```

Therefore, `Carry = 1` indicates that a borrow occurred.

For shift operations, `Carry` contains the bit shifted out:

```text
LEFT SHIFT  → Carry = A[15]
RIGHT SHIFT → Carry = A[0]
```

For logical and comparison operations, `Carry` is set to `0`.

---

### Zero Flag

The Zero flag is generated using:

```verilog
Zero = ~( |ALU_Out );
```

Therefore:

```text
ALU_Out = 0000  → Zero = 1
ALU_Out ≠ 0000  → Zero = 0
```

---

### Sign Flag

The Sign flag is directly connected to the most significant bit of the result:

```verilog
Sign = ALU_Out[15];
```

For a 16-bit two's-complement result:

```text
Sign = 0 → Positive / non-negative result
Sign = 1 → Negative result
```

---

### Parity Flag

The ALU generates an **even parity flag** using:

```verilog
Parity = ~^ALU_Out;
```

Therefore:

```text
Parity = 1 → Even number of 1s in ALU_Out
Parity = 0 → Odd number of 1s in ALU_Out
```

## Verification

A **self-checking Verilog testbench** was developed to verify the functionality of the ALU automatically.

The testbench verifies:

* Addition
* Addition with carry
* Subtraction
* Subtraction with borrow
* AND
* OR
* XOR
* NOT
* Left shift
* Right shift
* Comparison
* Carry flag
* Zero flag
* Sign flag
* Parity flag
* Boundary conditions

The testbench compares the actual ALU outputs and flags with the expected values and reports either `PASS` or `FAIL`.

## Synthesis Results

The ALU was synthesized using **Xilinx Vivado**.

| Resource     | Used | Utilization |
| :----------- | ---: | ----------: |
| Slice LUTs   |   96 |       0.29% |
| LUT as Logic |   96 |       0.29% |
| F7 Muxes     |   13 |       0.08% |
| Bonded I/O   |   55 |      26.19% |

### Resource Analysis

The design uses **96 Slice LUTs**, corresponding to **0.29%** of the available Slice LUT resources on the selected FPGA device.

The LUTs are used for the ALU's arithmetic, logical, comparison, shift, flag-generation, and operation-selection logic.

The design also uses **13 F7 multiplexers**, primarily for operation selection and associated combinational logic.

The **55 bonded I/O** resources are associated with the 16-bit input operands, 4-bit operation selector, 16-bit output, and status flags.

> **Note:** These synthesis values are specific to the FPGA device and Vivado synthesis configuration used. They may change after modifying the RTL or targeting a different FPGA device.
