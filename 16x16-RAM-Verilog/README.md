# 16x16 Synchronous RAM Design in Verilog

## Overview

This project implements a **16 × 16-bit single-port synchronous RAM** using Verilog HDL.

The memory contains **16 locations**, with each location capable of storing **16 bits of data**. The design supports synchronous write and synchronous read operations controlled by a clock signal.

The project was designed, simulated, verified, and synthesized using **Xilinx Vivado**.

## RAM Architecture

The memory is declared as:

```verilog
reg [15:0] memory [15:0];
```

This creates **16 memory locations**, where each location stores **16 bits**.

The 4-bit address selects one of the 16 memory locations.

```text
Address Range: 0 to 15
```

---

## Write Operation

When `we = 1`, the input data is written into the selected memory location on the positive edge of the clock.

```verilog
if (we)
    memory[addr] <= din;
```

---

## Read Operation

The data stored at the selected address is transferred to the output on the positive edge of the clock.

```verilog
dout <= memory[addr];
```

Therefore, this design implements a **synchronous read operation**.

---

## Simulation and Verification

The design was verified using a Verilog testbench and a self-checking verification approach.

The testbench verifies:

- Writing data to multiple memory locations
- Reading stored data
- Overwriting an existing memory location
- Lowest address boundary (`0`)
- Highest address boundary (`15`)
- Automatic comparison of expected and actual output data

### Resource Utilization

| Resource | Used | Available | Utilization |
|---|---:|---:|---:|
| Slice LUTs | 16 | 32,600 | ~0.05% |
| Slice Registers | 16 | 65,200 | ~0.02% |
| Bonded I/O | 38 | 210 | ~18.1% |
| BUFGCTRL | 1 | 32 | ~3.1% |

The design uses minimal FPGA logic resources. The 16 output registers correspond to the 16-bit registered output, while the I/O utilization reflects the 38 top-level input/output signals.
